# Desain awal Peta Belajar

Salinan sumber kanvas Claude Design "Desain Peta Belajar" (16 papan).
Kanvas aslinya: https://claude.ai/artifact/1TtYUGzULjcW5P5Fay18Mh

- `Main` sistem desain, `Logo` tiga konsep logo.
- Alur utama (bisa diklik): Beranda, Pertanyaan, Rencana, Jadwal, PetaJalur, Belajar, PanelCatatan.
- Mode Layar Lebar: LayarLebar, LayarLebarMenu (800 × 360).
- Layar lain: BukuCatatan, Ringkasan, Profil.
- Tema gelap: BerandaGelap, BelajarGelap.

Patokan: brief-desain-rctor.md. Kotak gelap bertuliskan "Pemutar resmi YouTube" hanyalah tempat
pemutar; di aplikasi, area itu diisi react-native-youtube-iframe tanpa apa pun di atasnya.
